# Monday Night Triples Dashboard

Create a brand-new standalone full-stack project for a duckpin bowling triples league website called “Monday Night Triples” at AMF Dundalk. This must be completely independent from the existing Pro Summer Singles project. Use a dark modern sports-dashboard aesthetic with charcoal, deep teal, aqua, and gold. Set up the initial application shell and public navigation for Home, Standings, Schedule, Results, Teams, Bowlers, and Stats, plus an Admin area. Do not invent bowling rules yet; I will send the complete league/scoring specification immediately after project creation.
